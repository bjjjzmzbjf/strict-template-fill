# 验收场景

这些场景用于维护规则和设计实际测试，不是已经完成的文档测试报告。执行测试时使用虚构数据，在记录中填写工具、样例、实际结果和完成范围。

| 场景 | 应观察到的结果 | 不合格表现 |
| --- | --- | --- |
| 已填写参考含旧姓名、日期和签名 | 母版仅清除可变内容，公共文字、段落和表格完整保留 | 旧信息残留，或清空时丢失样式与固定栏目 |
| 原稿字号杂乱、段落居中、空行很多 | 对应位置全部沿用母版格式 | 原稿样式污染母版，或所有槽位被统一成默认正文 |
| 原稿表格宽度、列数与母版不同 | 提取数据并映射到母版已有单元格；无法对应时说明 | 直接复制原稿表格替换母版结构 |
| 母版同一槽位包含粗体及上标 | 保留各格式段，填入后检查语义和样式 | 合并为一个默认格式 run，丢失上下标 |
| 编号 00127、电话或历史日期 | 字符值精确保留；只执行明确授权的转换 | 丢失前导零或将日期替换成当前日期 |
| 多份姓名相近、含不同签名 | 每份独立复制母版，按文件标识逐字段绑定 | 上份内容或签名进入下一份 |
| 原稿签名浮动且有白边 | 使用母版明确的图片槽位与规格；保留来源原图 | 沿用来源锚点、自动裁图或重画签名 |
| 长内容超出固定表格容量 | 明确报告冲突并继续其他文件 | 缩字、压行距、扩表格、移动日期或删除内容 |
| 表格最小行高或自动布局随内容扩展 | 比较实际尺寸，影响固定布局时报告冲突 | 只检查属性值相同就声称外观完全一致 |
| 缺少字体或渲染器 | 明确视觉验收未完成及具体原因 | 仅提取文字或检查 XML 后宣称每页合格 |
| 批量十份材料，每份多页 | 每份逐字段、全部页面检查，跨文件比较同类位置 | 只抽查首份、首尾页或只生成图片未查看 |
| 仅要求查错、润色或未提供格式依据 | 在实际授权范围内处理或先确定模板 | 擅自触发批量套版、套用无关排版预设 |

评估技能更新时，应检查这些预期结果是否仍受入口规则约束。实际执行的样例应额外比较原稿内容、母版结构及渲染结果；规则检查不能代替文档测试。
